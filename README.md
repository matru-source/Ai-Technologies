# AI Technologies — Ideas | Innovation | Impact

A modern, high-performance web platform built for **AI Technologies**, a digital engineering agency and software solutions provider based in Bhubaneswar, Odisha.

---

## ⚡ Tech Stack

* **Core**: React 19, JavaScript (ESNext), HTML5 Semantic Architecture
* **Bundler & Tooling**: Vite 8, Rolldown runtime, Oxlint
* **3D Visuals & Canvas**: Three.js WebGL particle swarm & emblem halo
* **Styling & System**: Vanilla CSS design system with fluid clamp typography, glassmorphism & dark aesthetic
* **Icons & Animation**: Lucide React, Canvas Confetti

---

## 🛠️ Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v18.0.0 or later)
* npm (v9.0.0 or later)

### Installation

```bash
# Clone repository
git clone https://github.com/matru-source/Ai-Technologies.git

# Enter project directory
cd Ai-Technologies

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
